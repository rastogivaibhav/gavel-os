# T13 — approved guarded restart

Status IMPLEMENTED_UNVERIFIED pending privileged CI. Requires PR #30.

The trusted operator may invoke `gavel-enforcer restart <previous-cgroup> <approved-digest> <absolute-executable> [args...]` after previous guarded workload cleanup. Requires remote machine key, valid canonical SHA-256 effective launch digest, trusted cgroup parent and bpffs, and an exclusive predecessor lifecycle lease. Refuses if predecessor cgroup, any pin, or recovery receipt still exists. No destructive cleanup or automatic restart is implied. Fresh launch also enforces dedicated UID availability and all existing guarded admission checks. The supplied digest must match the freshly resolved policy; existing expected-digest environment constraint remains additive. No local-policy fallback.

All remote launches now re-fetch the effective policy after pinning, immediately before spawn; if unavailable, invalid, non-online or changed, refuse execution and clean up the empty cgroup. A remote policy can still change after the check; existing active watchdog detects changes on its polling cadence. This is not a signed approval token, one-time capability, durable predecessor identity registry, or instantaneous revocation. The operator is trusted to identify the actual predecessor, preserve dedicated UID assignment and approve the exact new effective configuration out of band. The command does not prevent a trusted operator using ordinary run directly. No automatic restart, retry loop, policy hot swap or replay of workload state. Old policy digest is not automatically accepted for a changed snapshot.

The 24th kernel assertion launches an actual remote guarded payload under the old snapshot, proves allowed/denied socket calls, and then exercises absent approval, stale digest, HTTP 503, changed policy between resolution and spawn, residual predecessor cgroup and held predecessor lease. All refusals require absent payload marker. Explicit new digest permits a fresh cgroup under the changed policy with opposite socket outcomes and no residual cgroups or pins. Existing active watchdog test separately proves termination on active policy loss. Full end-to-end automatic restart, boot-time behavior, independently signed policy authority and P0.7 remain outside this slice.
