# Guarded filesystem policy (developer preview)

Set the host-controlled GAVEL_AGENT_FS_POLICY environment variable to a JSON object, e.g. {"read":["/usr/lib","/opt/agent","/srv/agent/work"],"write":["/srv/agent/work"],"execute":["/opt/agent","/usr/lib"]}. Include all actual runtime dependencies (dynamic loader, libraries, application binaries). Use absolute existing paths. Directories authorize their subtrees. Aliases resolve before compilation; root and write/execute overlap are rejected. Write does not implicitly grant read. The operator must ensure policy paths and runtime dependencies are trusted and not modified concurrently. The agent receives no policy environment variable. Absence explicitly means network/process protection only; a configured invalid policy or missing Landlock ABI 3 is a launch error. No fallback to weaker rules. Requires util-linux setpriv with Landlock and seccomp support.

Scope: filesystem access rights handled by Landlock, not all file metadata operations or executable script semantics. Existing descriptors (including standard streams), FD passing, UNIX IPC, hardlinks and trusted helper processes require further threat analysis. Do not use real secrets in tests. No production safety claim until isolated kernel tests and independent validation pass.
